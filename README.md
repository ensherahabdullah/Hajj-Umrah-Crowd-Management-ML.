# Emergency Event Prediction in Hajj & Umrah Crowds

## Project Overview

This machine learning project aims to build and evaluate classification models that predict whether an emergency event may occur in Hajj and Umrah crowds based on crowd conditions, environmental factors, and individual-related features.

**Target Variable:** `Emergency_Event` (Yes/No)

## Dataset

The project uses a synthetic Hajj and Umrah crowd management dataset.

**Dataset Source:** [Hajj and Umrah Crowd Management Dataset – Kaggle](https://www.kaggle.com/datasets/ziya07/hajj-and-umrah-crowd-management-dataset)

## Machine Learning Models

- Decision Tree Classifier
- Random Forest Classifier
- XGBoost Classifier

## Model Evaluation

The models were evaluated using accuracy, classification reports, and confusion matrices.

Test accuracy was approximately 50%, indicating limited predictive performance. The results also suggest overfitting in the XGBoost model.

## Conclusion

This project applies classification models to emergency-event prediction in Hajj and Umrah crowds. The limited results highlight the need for more representative data and further model validation before any real-world application.
